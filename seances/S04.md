## Étapes de travail

### 1. Comprendre Navigator (15 min)

Flutter gère la navigation comme une **pile d'écrans** (stack) :
- `Navigator.push` → empile un nouvel écran
- `Navigator.pop` → dépile l'écran courant (retour)

Il existe deux styles de navigation :
- **Impérative** : `Navigator.push(context, MaterialPageRoute(...))`
- **Déclarative (routes nommées)** : `Navigator.pushNamed(context, '/add')`

Vous utiliserez les deux dans cette séance.

### 2. Création de l'écran d'ajout de tâche (40 min)

Créez `lib/screens/add_task_screen.dart` :

```dart
import 'package:flutter/material.dart';
import '../models/task.dart';

class AddTaskScreen extends StatefulWidget {
  const AddTaskScreen({super.key});

  @override
  State<AddTaskScreen> createState() => _AddTaskScreenState();
}

class _AddTaskScreenState extends State<AddTaskScreen> {
  final _formKey = GlobalKey<FormState>();
  final _titleController = TextEditingController();

  @override
  void dispose() {
    _titleController.dispose();
    super.dispose();
  }

  void _submit() {
    if (_formKey.currentState!.validate()) {
      final newTask = Task(
        id: DateTime.now().millisecondsSinceEpoch.toString(),
        title: _titleController.text.trim(),
      );
      Navigator.pop(context, newTask); // retourne la tâche à HomeScreen
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Nouvelle tâche')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                controller: _titleController,
                autofocus: true,
                decoration: const InputDecoration(
                  labelText: 'Titre de la tâche',
                  border: OutlineInputBorder(),
                ),
                validator: (value) {
                  if (value == null || value.trim().isEmpty) {
                    return 'Le titre ne peut pas être vide';
                  }
                  return null;
                },
              ),
              const SizedBox(height: 24),
              SizedBox(
                width: double.infinity,
                child: ElevatedButton(
                  onPressed: _submit,
                  child: const Text('Ajouter la tâche'),
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

> **À noter :** `Navigator.pop(context, newTask)` permet de **retourner une valeur** à l'écran précédent. C'est une technique importante.

> **À noter :** `dispose()` est appelé quand le widget est retiré de l'arbre. Il faut toujours libérer les `TextEditingController` ici pour éviter les fuites mémoire.

### 3. Mise à jour de HomeScreen (25 min)

Supprimez `_showAddTaskDialog` et remplacez le `FloatingActionButton` pour naviguer vers `AddTaskScreen` :

```dart
floatingActionButton: FloatingActionButton(
  onPressed: _navigateToAddTask,
  child: const Icon(Icons.add),
),
```

```dart
Future<void> _navigateToAddTask() async {
  final newTask = await Navigator.push<Task>(
    context,
    MaterialPageRoute(builder: (_) => const AddTaskScreen()),
  );
  if (newTask != null) {
    setState(() {
      _tasks.add(newTask);
    });
  }
}
```

> **Question :** Pourquoi `_navigateToAddTask` est-elle déclarée `async` ? Que se passe-t-il si l'utilisateur appuie sur le bouton retour sans valider ?

### 4. Routes nommées (20 min)

Configurez les routes nommées dans `main.dart` :

```dart
MaterialApp(
  title: 'To-Do List',
  initialRoute: '/',
  routes: {
    '/': (context) => const HomeScreen(),
    '/add': (context) => const AddTaskScreen(),
  },
)
```

Adaptez la navigation dans `HomeScreen` pour utiliser les routes nommées :

```dart
final newTask = await Navigator.pushNamed(context, '/add') as Task?;
```

### 5. Écran de détail d'une tâche (20 min)

Créez `lib/screens/task_detail_screen.dart`, un écran en lecture seule qui affiche les informations d'une tâche :

```dart
class TaskDetailScreen extends StatelessWidget {
  final Task task;
  const TaskDetailScreen({super.key, required this.task});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(task.title)),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text('Statut : ${task.isDone ? "Terminée" : "En cours"}'),
          ],
        ),
      ),
    );
  }
}
```

Dans `TaskTile`, rendez le `ListTile` tappable pour naviguer vers ce détail :

```dart
onTap: () => Navigator.push(
  context,
  MaterialPageRoute(builder: (_) => TaskDetailScreen(task: task)),
),
```
