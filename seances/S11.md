## Étapes de travail

### 1. SharedPreferences vs SQLite (15 min)

Lisez et comprenez ce tableau avant de coder :

| Critère | SharedPreferences | SQLite |
|---|---|---|
| Type de données | Clé/valeur simple | Table relationnelle |
| Adapté pour | Préférences, petits objets | Listes, données structurées |
| Requêtes | Non | Oui (WHERE, ORDER BY, etc.) |
| Performance sur grandes listes | Faible (charge tout en mémoire) | Bonne (chargement partiel) |
| Complexité | Faible | Moyenne |

> **Conclusion :** Pour une To-Do List avec tri, filtres et potentiellement des centaines de tâches, SQLite est la solution appropriée. `SharedPreferences` était une première étape pédagogique.

### 3. Schéma de la base de données (15 min)

Avant d'écrire du code, définissez votre schéma sur papier (ou dans un commentaire) :

```sql
CREATE TABLE tasks (
  id        TEXT PRIMARY KEY,
  title     TEXT NOT NULL,
  description TEXT NOT NULL DEFAULT '',
  is_done   INTEGER NOT NULL DEFAULT 0,   -- 0 = false, 1 = true
  priority  INTEGER NOT NULL DEFAULT 1,   -- 0=low, 1=normal, 2=high
  created_at INTEGER NOT NULL             -- timestamp en millisecondes
)
```

> **À noter :** SQLite ne possède pas de type `BOOLEAN`. On utilise `INTEGER` (0 ou 1). C'est une contrainte importante à garder en tête lors de la sérialisation.

### 4. Création du DatabaseHelper (50 min)

Créez `lib/services/database_helper.dart` :

```dart
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';
import '../models/task.dart';

class DatabaseHelper {
  static const _dbName    = 'todo_list.db';
  static const _dbVersion = 1;
  static const _tableName = 'tasks';

  // Singleton : une seule instance dans toute l'application
  DatabaseHelper._();
  static final DatabaseHelper instance = DatabaseHelper._();

  Database? _database;

  Future<Database> get database async {
    _database ??= await _initDatabase();
    return _database!;
  }

  Future<Database> _initDatabase() async {
    final dbPath = await getDatabasesPath();
    final path   = join(dbPath, _dbName);

    return openDatabase(
      path,
      version: _dbVersion,
      onCreate: _onCreate,
    );
  }

  Future<void> _onCreate(Database db, int version) async {
    await db.execute('''
      CREATE TABLE $_tableName (
        id          TEXT PRIMARY KEY,
        title       TEXT NOT NULL,
        description TEXT NOT NULL DEFAULT '',
        is_done     INTEGER NOT NULL DEFAULT 0,
        priority    INTEGER NOT NULL DEFAULT 1,
        created_at  INTEGER NOT NULL
      )
    ''');
  }

  // --- CRUD ---

  Future<void> insertTask(Task task) async {
    final db = await database;
    await db.insert(
      _tableName,
      _toMap(task),
      conflictAlgorithm: ConflictAlgorithm.replace,
    );
  }

  Future<List<Task>> getAllTasks() async {
    final db   = await database;
    final maps = await db.query(_tableName, orderBy: 'created_at ASC');
    return maps.map(_fromMap).toList();
  }

  Future<void> updateTask(Task task) async {
    final db = await database;
    await db.update(
      _tableName,
      _toMap(task),
      where: 'id = ?',
      whereArgs: [task.id],
    );
  }

  Future<void> deleteTask(String id) async {
    final db = await database;
    await db.delete(
      _tableName,
      where: 'id = ?',
      whereArgs: [id],
    );
  }

  // --- Sérialisation ---

  Map<String, dynamic> _toMap(Task task) {
    return {
      'id':          task.id,
      'title':       task.title,
      'description': task.description,
      'is_done':     task.isDone ? 1 : 0,
      'priority':    task.priority.index,
      'created_at':  int.parse(task.id), // l'id est un timestamp
    };
  }

  Task _fromMap(Map<String, dynamic> map) {
    return Task(
      id:          map['id'] as String,
      title:       map['title'] as String,
      description: map['description'] as String,
      isDone:      (map['is_done'] as int) == 1,
      priority:    Priority.values[map['priority'] as int],
    );
  }
}
```

> **Pattern Singleton :** `DatabaseHelper._()` est un constructeur privé. `static final instance` garantit qu'il n'existe qu'une seule instance de la base dans toute l'application. C'est essentiel pour éviter les conflits d'accès concurrent.
