## Étapes de travail

### 1. Ajout du champ dueDate au modèle (20 min)

Ajoutez `dueDate` à `Task` :

```dart
class Task {
  // ... champs existants
  DateTime? dueDate; // nullable : une tâche peut n'avoir pas de date

  Task({
    // ... paramètres existants
    this.dueDate,
  });

  Map<String, dynamic> toJson() {
    return {
      // ... champs existants
      'due_date': dueDate?.millisecondsSinceEpoch, // null si pas de date
    };
  }

  factory Task.fromJson(Map<String, dynamic> json) {
    return Task(
      // ... champs existants
      dueDate: json['due_date'] != null
          ? DateTime.fromMillisecondsSinceEpoch(json['due_date'] as int)
          : null,
    );
  }
}
```

#### Mise à jour du schéma SQLite

Ajoutez la colonne `due_date` dans `DatabaseHelper` :

```dart
// Dans _toMap()
'due_date': task.dueDate?.millisecondsSinceEpoch,

// Dans _fromMap()
dueDate: map['due_date'] != null
    ? DateTime.fromMillisecondsSinceEpoch(map['due_date'] as int)
    : null,
```

**Important :** Comme la base existe déjà sur votre émulateur, il faut gérer la migration. La façon la plus simple en développement est de désinstaller l'application (ce qui supprime la base) et de relancer. En production, on utiliserait le paramètre `onUpgrade` de `openDatabase`.

### 2. Sélecteur de date dans AddTaskScreen (25 min)

Ajoutez une variable d'état et un sélecteur de date :

```dart
DateTime? _selectedDueDate;

Future<void> _pickDueDate() async {
  final now  = DateTime.now();
  final date = await showDatePicker(
    context: context,
    initialDate: _selectedDueDate ?? now,
    firstDate: now,
    lastDate: now.add(const Duration(days: 365 * 2)),
  );
  if (date == null) return;

  // Optionnel : sélectionner aussi une heure
  final time = await showTimePicker(
    context: context,
    initialTime: TimeOfDay.fromDateTime(_selectedDueDate ?? now),
  );

  setState(() {
    _selectedDueDate = time == null
        ? date
        : DateTime(date.year, date.month, date.day, time.hour, time.minute);
  });
}
```

Ajoutez un bouton dans le formulaire :

```dart
ListTile(
  leading: const Icon(Icons.calendar_today),
  title: Text(
    _selectedDueDate == null
        ? 'Aucune date d\'échéance'
        : 'Échéance : ${_formatDate(_selectedDueDate!)}',
  ),
  trailing: _selectedDueDate != null
      ? IconButton(
          icon: const Icon(Icons.clear),
          onPressed: () => setState(() => _selectedDueDate = null),
        )
      : null,
  onTap: _pickDueDate,
),
```

```dart
String _formatDate(DateTime date) {
  return '${date.day.toString().padLeft(2, '0')}/'
      '${date.month.toString().padLeft(2, '0')}/'
      '${date.year} à '
      '${date.hour.toString().padLeft(2, '0')}:'
      '${date.minute.toString().padLeft(2, '0')}';
}
```

### 5. Service de notifications (30 min)

Créez `lib/services/notification_service.dart` :

```dart
import 'package:flutter_local_notifications/flutter_local_notifications.dart';

class NotificationService {
  NotificationService._();
  static final NotificationService instance = NotificationService._();

  final _plugin = FlutterLocalNotificationsPlugin();

  Future<void> init() async {
    const android = AndroidInitializationSettings('@mipmap/ic_launcher');
    const ios     = DarwinInitializationSettings();
    await _plugin.initialize(
      const InitializationSettings(android: android, iOS: ios),
    );
    await _requestPermissions();
  }

  Future<void> _requestPermissions() async {
    await _plugin
        .resolvePlatformSpecificImplementation<
            AndroidFlutterLocalNotificationsPlugin>()
        ?.requestNotificationsPermission();
  }

  Future<void> scheduleTaskReminder(String id, String title, DateTime dueDate) async {
    // Notifier 30 minutes avant l'échéance
    final notifTime = dueDate.subtract(const Duration(minutes: 30));
    if (notifTime.isBefore(DateTime.now())) return;

    await _plugin.schedule(
      id.hashCode,
      'Rappel : $title',
      'Cette tâche est due dans 30 minutes',
      notifTime,
      const NotificationDetails(
        android: AndroidNotificationDetails(
          'todo_reminders',
          'Rappels de tâches',
          importance: Importance.high,
          priority: Priority.high,
        ),
        iOS: DarwinNotificationDetails(),
      ),
    );
  }

  Future<void> cancelNotification(String id) async {
    await _plugin.cancel(id.hashCode);
  }
}
```

> **Note :** Sur les versions récentes d'Android (12+), `schedule` nécessite l'autorisation `SCHEDULE_EXACT_ALARM`. Sur les émulateurs, il peut être nécessaire de l'activer manuellement dans les paramètres système.

### 6. Intégration dans TaskProvider (15 min)

Appelez `NotificationService` lors de l'ajout et de la suppression de tâches :

```dart
Future<void> addTask(Task task) async {
  await DatabaseHelper.instance.insertTask(task);
  _tasks.add(task);
  if (task.dueDate != null) {
    await NotificationService.instance.scheduleTaskReminder(
      task.id, task.title, task.dueDate!,
    );
  }
  notifyListeners();
}

Future<void> deleteTask(String id) async {
  await DatabaseHelper.instance.deleteTask(id);
  await NotificationService.instance.cancelNotification(id);
  _tasks.removeWhere((t) => t.id == id);
  notifyListeners();
}
```

Initialisez `NotificationService` dans `main()` :

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await NotificationService.instance.init();
  await DatabaseHelper.instance.database;
  runApp(/* ... */);
}
```
