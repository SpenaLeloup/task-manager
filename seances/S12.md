### 1. Mise à jour du TaskProvider (40 min)

Remplacez `StorageService` par `DatabaseHelper` dans `TaskProvider` :

```dart
import '../services/database_helper.dart';

class TaskProvider extends ChangeNotifier {
  final List<Task> _tasks = [];
  bool _isLoading = true;

  bool get isLoading => _isLoading;

  TaskProvider() {
    _loadFromDatabase();
  }

  Future<void> _loadFromDatabase() async {
    final saved = await DatabaseHelper.instance.getAllTasks();
    _tasks.addAll(saved);
    _isLoading = false;
    notifyListeners();
  }

  Future<void> addTask(Task task) async {
    await DatabaseHelper.instance.insertTask(task);
    _tasks.add(task);
    notifyListeners();
  }

  Future<void> toggleTask(String id) async {
    final index = _tasks.indexWhere((t) => t.id == id);
    if (index != -1) {
      _tasks[index].isDone = !_tasks[index].isDone;
      await DatabaseHelper.instance.updateTask(_tasks[index]);
      notifyListeners();
    }
  }

  Future<void> deleteTask(String id) async {
    await DatabaseHelper.instance.deleteTask(id);
    _tasks.removeWhere((t) => t.id == id);
    notifyListeners();
  }

  Future<void> updateTask(Task updatedTask) async {
    final index = _tasks.indexWhere((t) => t.id == updatedTask.id);
    if (index != -1) {
      await DatabaseHelper.instance.updateTask(updatedTask);
      _tasks[index] = updatedTask;
      notifyListeners();
    }
  }

  // Filtrage, tri : code existant inchangé
}
```

> **Stratégie :** On garde la liste `_tasks` en mémoire comme **cache**. La base SQLite est la source de vérité, mais on ne recharge pas depuis la base à chaque opération — on met à jour les deux en même temps. C'est plus performant.

> **Question :** Que se passe-t-il si `addTask` échoue côté base de données mais que la tâche a déjà été ajoutée à `_tasks` ? Comment pourrait-on gérer ce cas ?

### 2. Adaptation de l'interface aux méthodes async (20 min)

Les méthodes du provider sont maintenant `async`. Dans les widgets, les appels via `context.read` restent identiques — Flutter gère la notification via `notifyListeners()` :

```dart
// Aucun changement nécessaire dans les widgets
context.read<TaskProvider>().addTask(newTask);
context.read<TaskProvider>().toggleTask(task.id);
```

Cependant, si vous voulez attendre la fin d'une opération avant de naviguer, utilisez `await` :

```dart
// Dans AddTaskScreen
await context.read<TaskProvider>().addTask(newTask);
if (mounted) Navigator.pop(context);
```

> **À noter :** `if (mounted)` vérifie que le widget est toujours dans l'arbre avant d'appeler `Navigator.pop`. C'est important après un `await` car le widget peut avoir été détruit entre-temps.

```dart
  final db    = await database;
  final total = Sqflite.firstIntValue(await db.rawQuery('SELECT COUNT(*) FROM $_tableName')) ?? 0;
  final done  = Sqflite.firstIntValue(await db.rawQuery('SELECT COUNT(*) FROM $_tableName WHERE is_done = 1')) ?? 0;
```

```dart
class TaskSearchDelegate extends SearchDelegate<String> {
  @override
  List<Widget> buildActions(BuildContext context) => [
    IconButton(icon: const Icon(Icons.clear), onPressed: () => query = ''),
  ];

  @override
  Widget buildLeading(BuildContext context) => IconButton(
    icon: const Icon(Icons.arrow_back),
    onPressed: () => close(context, ''),
  );

  @override
  Widget buildResults(BuildContext context) => _buildSearchResults(context);

  @override
  Widget buildSuggestions(BuildContext context) => _buildSearchResults(context);

  Widget _buildSearchResults(BuildContext context) {
    if (query.isEmpty) return const Center(child: Text('Tapez pour rechercher'));

    return FutureBuilder<List<Task>>(
      future: DatabaseHelper.instance.searchTasks(query),
      builder: (context, snapshot) {
        if (!snapshot.hasData) return const Center(child: CircularProgressIndicator());
        final tasks = snapshot.data!;
        if (tasks.isEmpty) return Center(child: Text('Aucun résultat pour "$query"'));
        return ListView.builder(
          itemCount: tasks.length,
          itemBuilder: (_, i) => TaskTile(task: tasks[i]),
        );
      },
    );
  }
}
```
