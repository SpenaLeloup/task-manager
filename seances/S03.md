### 1. Convertir HomeScreen en StatefulWidget (20 min)

`HomeScreen` est actuellement un `StatelessWidget`. La liste de tâches va évoluer, il faut passer à un `StatefulWidget`.

Dans VS Code, placez le curseur sur `StatelessWidget` dans `home_screen.dart` et utilisez le raccourci **`Ctrl+.`** → *Convert to StatefulWidget*.

Déplacez la liste `_tasks` dans le `State` :

```dart
class _HomeScreenState extends State<HomeScreen> {
  final List<Task> _tasks = [
    Task(id: '1', title: 'Apprendre Flutter'),
    Task(id: '2', title: 'Créer ma première app'),
    Task(id: '3', title: 'Faire les courses'),
  ];

  @override
  Widget build(BuildContext context) {
    // ...
  }
}
```

### 2. Cocher / décocher une tâche (25 min)

Modifiez `TaskTile` pour qu'il accepte un callback `onToggle` :

```dart
class TaskTile extends StatelessWidget {
  final Task task;
  final VoidCallback onToggle;

  const TaskTile({super.key, required this.task, required this.onToggle});

  @override
  Widget build(BuildContext context) {
    return ListTile(
      leading: Checkbox(
        value: task.isDone,
        onChanged: (_) => onToggle(),
      ),
      title: Text(
        task.title,
        style: TextStyle(
          decoration: task.isDone ? TextDecoration.lineThrough : null,
          color: task.isDone ? Colors.grey : null,
        ),
      ),
    );
  }
}
```

Dans `HomeScreen`, passez le callback :

```dart
TaskTile(
  task: task,
  onToggle: () {
    setState(() {
      _tasks[index].isDone = !_tasks[index].isDone;
    });
  },
)
```

### 3. Supprimer une tâche (25 min)

Ajoutez un bouton de suppression dans `TaskTile` (callback `onDelete`) et gérez la suppression dans `HomeScreen` :

```dart
setState(() {
  _tasks.removeAt(index);
});
```

Utilisez le widget `Dismissible` pour permettre la suppression par glissement horizontal :

```dart
Dismissible(
  key: Key(task.id),
  direction: DismissDirection.endToStart,
  background: Container(
    color: Colors.red,
    alignment: Alignment.centerRight,
    padding: const EdgeInsets.only(right: 16),
    child: const Icon(Icons.delete, color: Colors.white),
  ),
  onDismissed: (_) {
    setState(() {
      _tasks.removeAt(index);
    });
  },
  child: TaskTile(task: task, onToggle: () { /* ... */ }),
)
```

### 4. Ajouter une tâche (30 min)

Ajoutez un `FloatingActionButton` dans le `Scaffold` :

```dart
floatingActionButton: FloatingActionButton(
  onPressed: _showAddTaskDialog,
  child: const Icon(Icons.add),
),
```

Implémentez `_showAddTaskDialog` avec un `AlertDialog` :

```dart
void _showAddTaskDialog() {
  final controller = TextEditingController();
  showDialog(
    context: context,
    builder: (ctx) => AlertDialog(
      title: const Text('Nouvelle tâche'),
      content: TextField(
        controller: controller,
        autofocus: true,
        decoration: const InputDecoration(hintText: 'Titre de la tâche'),
      ),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(ctx),
          child: const Text('Annuler'),
        ),
        ElevatedButton(
          onPressed: () {
            if (controller.text.trim().isNotEmpty) {
              setState(() {
                _tasks.add(Task(
                  id: DateTime.now().millisecondsSinceEpoch.toString(),
                  title: controller.text.trim(),
                ));
              });
              Navigator.pop(ctx);
            }
          },
          child: const Text('Ajouter'),
        ),
      ],
    ),
  );
}
```

> **Question :** Pourquoi utilise-t-on `DateTime.now().millisecondsSinceEpoch.toString()` comme identifiant ? Est-ce une bonne solution à long terme ?
