## Étapes de travail

### 1. Définition du thème global (25 min)

Dans `main.dart`, définissez un thème complet pour votre application :

```dart
theme: ThemeData(
  colorScheme: ColorScheme.fromSeed(
    seedColor: Colors.indigo,       // couleur principale : à personnaliser
    brightness: Brightness.light,
  ),
  useMaterial3: true,
  appBarTheme: const AppBarTheme(
    centerTitle: true,
    elevation: 2,
  ),
  floatingActionButtonTheme: const FloatingActionButtonThemeData(
    shape: CircleBorder(),
  ),
  inputDecorationTheme: const InputDecorationTheme(
    border: OutlineInputBorder(),
    filled: true,
  ),
),
```

Choisissez une couleur `seedColor` qui vous correspond. Consultez la palette Material 3 : https://m3.material.io/theme-builder

> **Bonne pratique :** Centraliser le thème dans `main.dart` (ou dans un fichier `lib/theme.dart` dédié) permet de modifier l'apparence globale en un seul endroit.

### 2. Widget pour l'état vide (20 min)

Lorsque la liste est vide, affichez un message engageant plutôt qu'un écran blanc.

Créez `lib/widgets/empty_state.dart` :

```dart
import 'package:flutter/material.dart';

class EmptyState extends StatelessWidget {
  const EmptyState({super.key});

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Column(
        mainAxisAlignment: MainAxisAlignment.center,
        children: [
          Icon(
            Icons.check_circle_outline,
            size: 80,
            color: Theme.of(context).colorScheme.primary.withOpacity(0.4),
          ),
          const SizedBox(height: 16),
          Text(
            'Aucune tâche pour le moment',
            style: Theme.of(context).textTheme.titleMedium,
          ),
          const SizedBox(height: 8),
          Text(
            'Appuyez sur + pour ajouter votre première tâche',
            style: Theme.of(context).textTheme.bodyMedium?.copyWith(
              color: Colors.grey,
            ),
            textAlign: TextAlign.center,
          ),
        ],
      ),
    );
  }
}
```

Dans `HomeScreen`, affichez `EmptyState` lorsque `_tasks` est vide :

```dart
body: _tasks.isEmpty
    ? const EmptyState()
    : ListView.builder(/* ... */),
```

### 3. Indicateur visuel de priorité dans TaskTile (20 min)

Ajoutez un indicateur coloré à gauche de chaque tâche selon sa priorité :

```dart
// Dans TaskTile
Color _priorityColor() {
  switch (task.priority) {
    case Priority.high:   return Colors.red;
    case Priority.normal: return Colors.orange;
    case Priority.low:    return Colors.green;
  }
}

// Dans build()
Card(
  margin: const EdgeInsets.symmetric(horizontal: 8, vertical: 4),
  child: Row(
    children: [
      Container(
        width: 6,
        height: 60,
        decoration: BoxDecoration(
          color: _priorityColor(),
          borderRadius: const BorderRadius.only(
            topLeft: Radius.circular(4),
            bottomLeft: Radius.circular(4),
          ),
        ),
      ),
      Expanded(
        child: ListTile(/* contenu existant */),
      ),
    ],
  ),
)
```

### 4. Personnalisation de l'icône de l'application (20 min)

#### 4a. Préparez votre icône

Créez ou téléchargez une image PNG **1024×1024 pixels** pour représenter votre application.  
Placez-la dans `assets/icon/app_icon.png` (créez le dossier si besoin).

#### 4b. Ajoutez la dépendance

Dans `pubspec.yaml`, ajoutez :

```yaml
dev_dependencies:
  flutter_launcher_icons: ^0.14.3

flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/icon/app_icon.png"
  min_sdk_android: 21
  web:
    generate: false
```

#### 4c. Installez et générez

```bash
flutter pub get
dart run flutter_launcher_icons
```

#### 4d. Vérifiez

Relancez l'application et vérifiez que votre icône apparaît sur l'émulateur (écran d'accueil ou tiroir d'applications).

> **Remarque :** Si l'icône ne s'actualise pas, désinstallez l'application de l'émulateur et relancez `flutter run`.

### 5. Ajout du sélecteur de priorité dans AddTaskScreen (15 min)

Ajoutez un `DropdownButtonFormField` pour choisir la priorité dans le formulaire :

```dart
DropdownButtonFormField<Priority>(
  value: _selectedPriority,
  decoration: const InputDecoration(
    labelText: 'Priorité',
    prefixIcon: Icon(Icons.flag),
  ),
  items: const [
    DropdownMenuItem(value: Priority.low,    child: Text('Basse')),
    DropdownMenuItem(value: Priority.normal, child: Text('Normale')),
    DropdownMenuItem(value: Priority.high,   child: Text('Haute')),
  ],
  onChanged: (value) => setState(() => _selectedPriority = value!),
),
```

Déclarez `_selectedPriority` dans l'état :

```dart
Priority _selectedPriority = Priority.normal;
```

Et incluez-le lors de la création de la tâche :

```dart
final newTask = Task(
  id: DateTime.now().millisecondsSinceEpoch.toString(),
  title: _titleController.text.trim(),
  description: _descriptionController.text.trim(),
  priority: _selectedPriority,
);
```
