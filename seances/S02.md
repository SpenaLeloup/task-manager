## Étapes de travail

### 1. Création du modèle de tâche (20 min)

Créez le fichier `lib/models/task.dart` :

```dart
class Task {
  final String id;
  String title;
  bool isDone;

  Task({
    required this.id,
    required this.title,
    this.isDone = false,
  });
}
```

> **Question à réfléchir :** Pourquoi `id` est-il `final` alors que `title` et `isDone` ne le sont pas ?

### 2. Création de l'écran principal (30 min)

Créez le fichier `lib/screens/home_screen.dart` :

```dart
import 'package:flutter/material.dart';
import '../models/task.dart';

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  // Liste statique de tâches pour commencer
  static final List<Task> _tasks = [
    Task(id: '1', title: 'Apprendre Flutter'),
    Task(id: '2', title: 'Créer ma première app'),
    Task(id: '3', title: 'Faire les courses'),
    Task(id: '4', title: 'Lire 30 minutes'),
    Task(id: '5', title: 'Faire du sport'),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Mes tâches'),
      ),
      body: ListView.builder(
        itemCount: _tasks.length,
        itemBuilder: (context, index) {
          final task = _tasks[index];
          return ListTile(
            leading: const Icon(Icons.radio_button_unchecked),
            title: Text(task.title),
            trailing: const Icon(Icons.chevron_right),
          );
        },
      ),
    );
  }
}
```

### 3. Mise à jour de main.dart (10 min)

Modifiez `lib/main.dart` pour utiliser `HomeScreen` :

```dart
import 'package:flutter/material.dart';
import 'screens/home_screen.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'To-Do List',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
        useMaterial3: true,
      ),
      home: const HomeScreen(),
    );
  }
}
```

### 4. Amélioration visuelle du ListTile (25 min)

Enrichissez chaque `ListTile` pour qu'il affiche :
- Une icône différente selon que la tâche est faite ou non (`Icons.check_circle` vs `Icons.radio_button_unchecked`)
- Le texte barré (`TextDecoration.lineThrough`) si la tâche est terminée
- Une couleur grisée pour les tâches terminées

Pour tester, passez manuellement `isDone: true` sur une ou deux tâches de la liste statique.

### 5. Séparation en widget dédié (25 min)

Créez le fichier `lib/widgets/task_tile.dart` et extrayez la logique d'affichage d'une tâche dans un widget `TaskTile` :

```dart
import 'package:flutter/material.dart';
import '../models/task.dart';

class TaskTile extends StatelessWidget {
  final Task task;

  const TaskTile({super.key, required this.task});

  @override
  Widget build(BuildContext context) {
    // À compléter : reprendre le contenu du ListTile de HomeScreen
  }
}
```

Utilisez `TaskTile` dans `HomeScreen` à la place du `ListTile` inline.

> **Pourquoi extraire un widget ?** C'est une bonne pratique qui rend le code plus lisible et réutilisable. Habituez-vous à le faire dès qu'un widget devient complexe.
