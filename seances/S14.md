### 1. Remplacement de ListView par AnimatedList (40 min)

`AnimatedList` anime automatiquement l'insertion et la suppression d'éléments.

Dans `HomeScreen` (ou dans le widget `_TaskList`), remplacez `ListView.builder` par `AnimatedList` :

```dart
class _TaskList extends StatefulWidget {
  final TaskFilter filter;
  const _TaskList({required this.filter});

  @override
  State<_TaskList> createState() => _TaskListState();
}

class _TaskListState extends State<_TaskList> {
  final GlobalKey<AnimatedListState> _listKey = GlobalKey<AnimatedListState>();
  List<Task> _currentTasks = [];

  @override
  Widget build(BuildContext context) {
    final tasks = context.watch<TaskProvider>().tasks;
    _syncList(tasks);

    if (tasks.isEmpty) return const EmptyState();

    return AnimatedList(
      key: _listKey,
      initialItemCount: _currentTasks.length,
      itemBuilder: (context, index, animation) {
        return _buildItem(_currentTasks[index], animation);
      },
    );
  }

  Widget _buildItem(Task task, Animation<double> animation) {
    return SizeTransition(
      sizeFactor: animation,
      child: Dismissible(
        key: Key(task.id),
        direction: DismissDirection.endToStart,
        onDismissed: (_) => _removeTask(task),
        background: Container(
          color: Colors.red,
          alignment: Alignment.centerRight,
          padding: const EdgeInsets.only(right: 16),
          child: const Icon(Icons.delete, color: Colors.white),
        ),
        child: TaskTile(task: task),
      ),
    );
  }

  void _syncList(List<Task> newTasks) {
    // Ajouter les nouvelles tâches
    for (int i = 0; i < newTasks.length; i++) {
      if (i >= _currentTasks.length || _currentTasks[i].id != newTasks[i].id) {
        _currentTasks.insert(i, newTasks[i]);
        _listKey.currentState?.insertItem(i);
      }
    }
    // Supprimer les tâches disparues
    for (int i = _currentTasks.length - 1; i >= 0; i--) {
      if (!newTasks.any((t) => t.id == _currentTasks[i].id)) {
        final removed = _currentTasks.removeAt(i);
        _listKey.currentState?.removeItem(
          i,
          (context, animation) => _buildItem(removed, animation),
        );
      }
    }
  }

  void _removeTask(Task task) {
    context.read<TaskProvider>().deleteTask(task.id);
  }
}
```

> **À comprendre :** `_syncList` compare l'ancienne et la nouvelle liste pour déclencher les animations au bon moment. C'est une technique courante pour synchroniser un `AnimatedList` avec une source de données externe.

### 2. Animation de complétion dans TaskTile (20 min)

Animez le changement d'état (fait / non fait) avec `AnimatedContainer` :

```dart
class TaskTile extends StatelessWidget {
  // ...

  @override
  Widget build(BuildContext context) {
    return AnimatedContainer(
      duration: const Duration(milliseconds: 300),
      curve: Curves.easeInOut,
      decoration: BoxDecoration(
        color: task.isDone
            ? Colors.grey.withOpacity(0.1)
            : Theme.of(context).colorScheme.surface,
        borderRadius: BorderRadius.circular(8),
      ),
      margin: const EdgeInsets.symmetric(horizontal: 8, vertical: 4),
      child: ListTile(
        // ... contenu existant
      ),
    );
  }
}
```

Pour la checkbox, utilisez `AnimatedSwitcher` pour animer la transition d'icône :

```dart
leading: AnimatedSwitcher(
  duration: const Duration(milliseconds: 200),
  child: Checkbox(
    key: ValueKey(task.isDone), // clé pour déclencher l'animation
    value: task.isDone,
    onChanged: (_) => context.read<TaskProvider>().toggleTask(task.id),
  ),
),
```

### 3. Transition Hero entre HomeScreen et TaskDetailScreen (25 min)

`Hero` crée une animation de transition partagée entre deux écrans.

Dans `TaskTile`, enveloppez l'icône principale dans un `Hero` :

```dart
leading: Hero(
  tag: 'task-icon-${task.id}',
  child: CircleAvatar(
    backgroundColor: _priorityColor().withOpacity(0.2),
    child: Icon(
      task.isDone ? Icons.check : Icons.radio_button_unchecked,
      color: _priorityColor(),
    ),
  ),
),
```

Dans `TaskDetailScreen`, utilisez le même tag :

```dart
Hero(
  tag: 'task-icon-${task.id}',
  child: CircleAvatar(
    radius: 40,
    backgroundColor: _priorityColor(task.priority).withOpacity(0.2),
    child: Icon(
      task.isDone ? Icons.check : Icons.radio_button_unchecked,
      size: 40,
      color: _priorityColor(task.priority),
    ),
  ),
),
```

> **À noter :** Le tag `Hero` doit être **unique** dans la page et **identique** dans les deux écrans pour que l'animation fonctionne.

### 4. SnackBar de confirmation après suppression (15 min)

Après une suppression par glissement, affichez une `SnackBar` avec une option "Annuler" :

```dart
onDismissed: (_) async {
  final taskCopy = task; // copie avant suppression
  await context.read<TaskProvider>().deleteTask(task.id);

  if (context.mounted) {
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text('"${taskCopy.title}" supprimée'),
        action: SnackBarAction(
          label: 'Annuler',
          onPressed: () {
            context.read<TaskProvider>().addTask(taskCopy);
          },
        ),
        duration: const Duration(seconds: 4),
      ),
    );
  }
},
```
