# Séance 1 — Installation & Découverte de Flutter

**Durée :** 2 heures  
**Travail :** individuel

---

## Objectifs pédagogiques

- Installer et configurer l'environnement de développement Flutter
- Installer Python et vérifier son fonctionnement (nécessaire pour le journal de bord)
- Comprendre la structure d'un projet Flutter
- Exécuter une application sur un émulateur ou un appareil physique
- Faire son premier commit Git

---

## Prérequis

- Aucun prérequis Flutter (première séance)
- Avoir un compte GitHub (nécessaire pour GitHub Classroom)
- Avoir accepté l'invitation GitHub Classroom et cloné le dépôt

---

## Étapes de travail

### 1. Installation de l'environnement (40 min)

#### Flutter, VS Code et Android Studio

1. Installez le SDK Flutter : https://docs.flutter.dev/get-started/install
2. Installez VS Code avec l'extension **Flutter** (identifiant : `Dart-Code.flutter`)
3. Installez Android Studio pour l'émulateur Android
4. Vérifiez votre installation Flutter dans un terminal :
   ```bash
   flutter doctor
   ```
   Tous les éléments doivent afficher une coche verte. Signalez immédiatement tout problème à l'enseignant.

#### Python (nécessaire pour le journal de bord)

Le script `journal.py` fourni dans le dépôt nécessite **Python 3.8 ou supérieur**.

**Vérifiez si Python est déjà installé :**
```bash
python --version
# ou, selon votre système :
python3 --version
```

**Si Python n'est pas installé :**

- **macOS** : installez-le via le site officiel https://www.python.org/downloads/ ou via Homebrew :
  ```bash
  brew install python
  ```
- **Windows** : téléchargez l'installateur sur https://www.python.org/downloads/  
  Cochez impérativement **"Add Python to PATH"** lors de l'installation.
- **Linux** : Python est généralement pré-installé. Sinon :
  ```bash
  sudo apt install python3
  ```

**Vérifiez l'installation :**
```bash
python --version
```
La version affichée doit être 3.8 ou supérieure.

**Testez le script du journal :**
```bash
# Depuis la racine du dépôt cloné
python journal.py
```
Le script doit afficher un message d'erreur indiquant qu'aucun commit Git n'a encore été effectué — c'est normal à ce stade. Il ne doit pas afficher d'erreur Python.

### 2. Création du projet (10 min)

1. Dans le terminal, placez-vous dans le dossier cloné depuis GitHub Classroom
2. Créez le projet Flutter :
   ```bash
   flutter create --org fr.université todo_list
   ```
3. Ouvrez le projet dans VS Code :
   ```bash
   code todo_list
   ```

### 3. Exploration de la structure du projet (20 min)

Examinez les fichiers et dossiers suivants et notez leur rôle dans votre journal :

| Fichier / Dossier | Rôle |
|---|---|
| `lib/main.dart` | Point d'entrée de l'application |
| `pubspec.yaml` | Dépendances et métadonnées du projet |
| `android/` | Code natif Android |
| `ios/` | Code natif iOS |
| `test/` | Tests automatisés |

### 4. Lancement sur émulateur (20 min)

1. Démarrez un émulateur Android depuis Android Studio (AVD Manager)
2. Dans VS Code, appuyez sur **F5** ou lancez :
   ```bash
   flutter run
   ```
3. Observez l'application compteur par défaut de Flutter
4. Modifiez le texte `'You have pushed the button this many times:'` dans `main.dart` par votre prénom, et observez le **hot reload** (sauvegardez le fichier)

### 5. Nettoyage du projet (15 min)

Remplacez le contenu de `lib/main.dart` par le code minimal suivant :

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'To-Do List',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
        useMaterial3: true,
      ),
      home: Scaffold(
        appBar: AppBar(title: const Text('Mes tâches')),
        body: const Center(child: Text('Bienvenue dans votre To-Do List')),
      ),
    );
  }
}
```

Vérifiez que l'application se lance correctement.

### 6. Premier commit Git (10 min)

```bash
git add .
git commit -m "init: création du projet Flutter To-Do List"
git push
```
