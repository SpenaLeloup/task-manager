### 1. Enum de tri et logique dans TaskProvider (30 min)

Ajoutez un `enum` pour les critères de tri :

```dart
enum SortCriteria { createdDate, priority, alphabetical, completionStatus }
```

Ajoutez le tri dans `TaskProvider` :

```dart
SortCriteria _sortCriteria = SortCriteria.createdDate;
bool _sortAscending = true;

SortCriteria get sortCriteria => _sortCriteria;
bool get sortAscending => _sortAscending;

void setSortCriteria(SortCriteria criteria) {
  if (_sortCriteria == criteria) {
    _sortAscending = !_sortAscending; // inverser si même critère
  } else {
    _sortCriteria = criteria;
    _sortAscending = true;
  }
  notifyListeners();
}

List<Task> get tasks {
  List<Task> filtered = /* filtrage existant */;
  return _sorted(filtered);
}

List<Task> _sorted(List<Task> list) {
  final sorted = [...list]; // copie pour ne pas muter l'original
  sorted.sort((a, b) {
    int cmp;
    switch (_sortCriteria) {
      case SortCriteria.createdDate:
        cmp = a.id.compareTo(b.id); // l'id est basé sur le timestamp
      case SortCriteria.priority:
        cmp = b.priority.index.compareTo(a.priority.index); // high > normal > low
      case SortCriteria.alphabetical:
        cmp = a.title.toLowerCase().compareTo(b.title.toLowerCase());
      case SortCriteria.completionStatus:
        cmp = a.isDone == b.isDone ? 0 : (a.isDone ? 1 : -1);
    }
    return _sortAscending ? cmp : -cmp;
  });
  return List.unmodifiable(sorted);
}
```

> **Question :** Pourquoi crée-t-on une copie avec `[...list]` avant de trier ? Que se passerait-il si on triait `list` directement ?

### 2. Menu de tri dans l'AppBar (25 min)

```dart
actions: [
  PopupMenuButton<SortCriteria>(
    icon: const Icon(Icons.sort),
    tooltip: 'Trier par',
    onSelected: (criteria) {
      context.read<TaskProvider>().setSortCriteria(criteria);
```

```dart
PopupMenuItem<SortCriteria> _sortItem(SortCriteria criteria, String label, IconData icon) {
  return PopupMenuItem(
    value: criteria,
    child: Row(
      children: [
        Icon(icon, size: 20),
        const SizedBox(width: 8),
        Text(label),
      ],
    ),
  );
}
```

### 4. Affichage enrichi de la priorité (20 min)

Dans `TaskTile`, remplacez la barre colorée par un `Chip` de priorité plus explicite :

```dart
Widget _priorityChip() {
  switch (task.priority) {
    case Priority.high:
      return const Chip(
        label: Text('Haute', style: TextStyle(fontSize: 11)),
        avatar: Icon(Icons.flag, size: 14, color: Colors.red),
        backgroundColor: Color(0xFFFFEBEE),
        padding: EdgeInsets.zero,
        materialTapTargetSize: MaterialTapTargetSize.shrinkWrap,
      );
    case Priority.normal:
      return const Chip(/* Orange */);
    case Priority.low:
      return const Chip(/* Vert */);
  }
}
```

Intégrez ce chip dans le `ListTile` avec la propriété `subtitle` :


Ajoutez un menu contextuel (appui long) sur chaque `TaskTile` pour changer rapidement la priorité :

```dart
GestureDetector(

)
```

```dart
void _showPriorityMenu(BuildContext context) {
  showModalBottomSheet(
    context: context,
    builder: (_) => Column(
      mainAxisSize: MainAxisSize.min,
      children: Priority.values.map((p) => ListTile(
        leading: Icon(Icons.flag, color: _priorityColor(p)),
        title: Text(_priorityLabel(p)),
        onTap: () {
          // Créer une copie de la tâche avec la nouvelle priorité
          final updated = Task(
            id: task.id,
            title: task.title,
            description: task.description,
            isDone: task.isDone,
            priority: p,
          );
          context.read<TaskProvider>().updateTask(updated);
          Navigator.pop(context);
        },
      )).toList(),
    ),
  );
}
```
