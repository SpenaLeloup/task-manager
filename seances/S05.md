### 1. Enrichissement du modèle Task (20 min)

Ajoutez deux champs à `Task` : une description optionnelle et un niveau de priorité (que vous utiliserez pleinement en S9) :

```dart
enum Priority { low, normal, high }

class Task {
  final String id;
  String title;
  String description;
  bool isDone;
  Priority priority;

  Task({
    required this.id,
    required this.title,
    this.description = '',
    this.isDone = false,
    this.priority = Priority.normal,
  });
}
```

> **Question :** Pourquoi utilise-t-on un `enum` plutôt qu'une chaîne de caractères pour la priorité ?

Vérifiez que l'application compile toujours après cet ajout. Corrigez les éventuelles erreurs.

### 2. Formulaire complet dans AddTaskScreen (50 min)

Remplacez le formulaire minimal de la S4 par un formulaire complet avec deux champs :

#### Champ titre (obligatoire)

```dart
TextFormField(
  controller: _titleController,
  autofocus: true,
  decoration: const InputDecoration(
    labelText: 'Titre *',
    hintText: 'Ex. : Faire les courses',
    border: OutlineInputBorder(),
    prefixIcon: Icon(Icons.task_alt),
  ),
  textCapitalization: TextCapitalization.sentences,
  validator: (value) {
    if (value == null || value.trim().isEmpty) {
      return 'Le titre est obligatoire';
    }
    if (value.trim().length < 3) {
      return 'Le titre doit comporter au moins 3 caractères';
    }
    return null;
  },
),
```

#### Champ description (optionnel)

```dart
const SizedBox(height: 16),
TextFormField(
  controller: _descriptionController,
  decoration: const InputDecoration(
    labelText: 'Description (optionnelle)',
    hintText: 'Précisez si nécessaire...',
    border: OutlineInputBorder(),
    prefixIcon: Icon(Icons.notes),
  ),
  maxLines: 3,
  textCapitalization: TextCapitalization.sentences,
),
```

N'oubliez pas de déclarer et de disposer `_descriptionController` :

```dart
final _descriptionController = TextEditingController();

@override
void dispose() {
  _titleController.dispose();
  _descriptionController.dispose();
  super.dispose();
}
```

#### Soumission enrichie

```dart
void _submit() {
  if (_formKey.currentState!.validate()) {
    final newTask = Task(
      id: DateTime.now().millisecondsSinceEpoch.toString(),
      title: _titleController.text.trim(),
      description: _descriptionController.text.trim(),
    );
    Navigator.pop(context, newTask);
  }
}
```

### 3. Affichage de la description dans TaskDetailScreen (20 min)

Mettez à jour `TaskDetailScreen` pour afficher la description si elle n'est pas vide :

```dart
if (task.description.isNotEmpty) ...[
  const SizedBox(height: 12),
  const Text('Description :', style: TextStyle(fontWeight: FontWeight.bold)),
  const SizedBox(height: 4),
  Text(task.description),
],
```

> **Astuce Dart :** L'opérateur `...[]` (spread conditionnel) permet d'insérer plusieurs widgets dans une liste de façon conditionnelle. C'est un idiome très courant en Flutter.

### 4. Modifier une tâche existante (30 min)

`AddTaskScreen` peut aussi servir à **modifier** une tâche. Adaptez-le pour accepter une tâche optionnelle en paramètre :

```dart
class AddTaskScreen extends StatefulWidget {
  final Task? taskToEdit; // null = ajout, non null = modification

  const AddTaskScreen({super.key, this.taskToEdit});
  // ...
}
```

Dans `initState`, pré-remplissez les champs si une tâche est fournie :

```dart
@override
void initState() {
  super.initState();
  if (widget.taskToEdit != null) {
    _titleController.text = widget.taskToEdit!.title;
    _descriptionController.text = widget.taskToEdit!.description;
  }
}
```

Adaptez le titre de l'`AppBar` et le bouton selon le mode (ajout ou modification) :

```dart
AppBar(
  title: Text(widget.taskToEdit == null ? 'Nouvelle tâche' : 'Modifier la tâche'),
)
```

Dans `HomeScreen`, ajoutez un bouton de modification dans `TaskTile` ou `TaskDetailScreen` qui navigue vers `AddTaskScreen(taskToEdit: task)`.
